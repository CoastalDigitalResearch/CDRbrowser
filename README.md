# CDRbrowser

100% AI-built and AI-maintained web browser, by Coastal Digital Research.

A clean-slate, standards-compliant browser with a Rust web engine and a native AI synthesis plane — featuring video summaries, audio briefings, source collation, and agentic browsing. Not Chromium or Firefox-derived.

## Architecture

- **Web Engine**: Rust HTML5 parser, CSS layout, wgpu compositor, QuickJS++ JS engine, HTTP/2/3
- **AI Synthesis Plane**: MCP/A2A orchestrator, multimodal pipelines, source discovery, memory fabric
- **Security**: Capability-based sandboxing, per-site WASM containers
- **Self-maintenance**: AI PR authoring with WPT-gated CI
